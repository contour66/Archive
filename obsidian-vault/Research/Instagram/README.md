# Instagram Research

This folder contains automated research findings from Instagram scraping.

## Structure

- **Daily_Reports/**: Summary reports generated daily
- **Viral_Posts/**: High-performing posts organized by niche category
- **Top_Performers/**: Best performing posts across all categories
- **Content_Patterns/**: Insights and patterns extracted from viral content

## Categories

- **fragrance**: Le Labo, Tom Ford, Byredo, Aesop, etc.
- **surf**: California surf culture, ocean lifestyle
- **motorcycles**: Vintage bikes, custom builds, riding culture
- **muay_thai**: Training, fighters, gyms
- **music**: Jazz, vinyl, music venues
- **art**: Architecture, craftsmanship, design
- **travel**: California, luxury hotels, boutique stays
- **food**: Specialty coffee, fine dining, California cuisine
- **grooming**: Men's grooming, skincare, wellness

## Data Source

All content scraped via Apify Instagram actors:
- Hashtag Scraper
- Profile Scraper
- Post Scraper

## Scoring Criteria

Posts are scored based on:
1. **Views** (primary) - >10k minimum
2. **Engagement Rate** (secondary) - >2% minimum
3. **Saves** (tertiary) - indicates high-value content
4. **Dapper Singh Relevance** (0-10 score)

## Usage

1. Browse categories for inspiration
2. Check Top_Performers for best posts
3. Review Content_Patterns for insights
4. Add high-scoring posts to Recreation Queue in Clarity app
